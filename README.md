# RyzenHub — Сборка и ремонт ПК

Сайт сервиса сборки, ремонта и обслуживания компьютеров в Томске.

**Живой сайт:** https://sui-ba.github.io/compville-site/

## Что внутри

- Тёмный премиум-дизайн (цвета логотипа: cyan + orange)
- **Готовые сборки** — 6 конфигураций с фильтрами (офис, игры, монтаж, бюджет)
- Можно взять готовую или **собрать свою** через анкету
- Раздел **Услуги** (сборка, ремонт, чистка, апгрейд, ПО, доставка)
- Многошаговая анкета заявок
- Отправка в Discord / Telegram
- Админка `/admin.html` (пароль: `ryzen2026`)
- Соглашение и Политика конфиденциальности

## Настройка уведомлений

```js
const DISCORD_WEBHOOK = "https://discord.com/api/webhooks/...";
```
