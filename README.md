# Compville — Сборка ПК на заказ

Премиальный сайт в стиле Apple для сервиса сборки и настройки компьютеров.

## Что внутри

- **Готовые сборки** — 6 конфигураций (офис, игры, монтаж, топ) с фильтрами
- **Сборка на заказ** — многошаговая анкета
- **Заявки сохраняются** в localStorage
- **Адаптив** под мобильные
- Ссылки на профиль Авито
